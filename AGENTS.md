# StairPlanner agent guide

Project brief: docs/ (start with the brief or design brief). Product rules and scope are in those docs.

## Backlog.md

Open work is tracked on the Backlog.md board in `backlog/`. Start with `backlog task list --plain`, and read a task in full with `backlog task <id> --plain` before starting it. Settled decisions: `backlog decision list --plain`. Create and update tasks with the `backlog` CLI, not by hand-editing task files. Use `backlog browser` for the web view. Auto-commit is on.
